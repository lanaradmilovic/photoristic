# 0013 — Group = interchangeable frames; wide vs tight are separate

- Status: superseded by [0014](0014-group-definition-v2.md)
- Date: 2026-10-19
- Decided by: the user (review of talici 4a)

## Decision (historic)
- A group = interchangeable frames, not "same scene"; a wide and a tight shot are separate groups.
- Congratulation-line hugs: one group per person/hug, never merged (all guests are memories).
- People photos: strict thresholds. No-people photos: relaxed rules ([0007](0007-relaxed-rules-without-people.md)).
- Splits caused by smoke bombs or global appearance changes are acceptable.

## Why superseded
Reviewing face-driven changes on 2026-11-11, the user rated most wide/tight chains of the same
people as good, which contradicts "wide vs tight = separate". The 4a `labels.json` (2026-11-10) may
partly follow this old rule.
